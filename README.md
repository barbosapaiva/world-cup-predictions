# World Cup Predictions

## Overview
This project was born from two simple ideas: the biggest football tournament in the world is coming, and I want to win some dinners from my friends.
For years, this kind of prediction game was managed in Excel, with little visibility during the competition and a lot of manual work for the organizer. I decided to turn that process into a web platform, combining something fun with a technical project where I can apply backend engineering and data engineering concepts.
The goal is to let users create private leagues, invite friends, submit match predictions and special tournament predictions, follow rankings, and view statistics throughout the competition.
